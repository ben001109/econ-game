# Internal SDK

The version-controlled package lives at [`packages/econ-game-sdk`](../../packages/econ-game-sdk/README.md). It is a dependency-free TypeScript SDK for the HTTP endpoints currently implemented in this repository, not a promise that those endpoints are the approved future product API.

Use the package README for installation, mock-only verification, supported client modules, and error handling. Use [the current HTTP surface](current-http-surface.md) for source links and the review checklist. The architecture record remains authoritative for future contracts and explicitly identifies the Python/uv services as preview-only.
