## Repository-scoped support

- `econ-game-node-quality-gate` 是可攜 scaffold，不代表已安裝或自動載入。要供 Hermes 使用，應由 Build／CI owner 審核後複製至 `~/.hermes/skills/econ-game/`；要供 Codex 使用，應由其 skill owner 依執行環境安裝。兩者都不是本文件的自動動作。
- [developer-platform-roadmap.md](developer-platform-roadmap.md) 管理現有 internal SDK snapshot 與未來正式 shared-contract 的不同 gate。`packages/econ-game-sdk` 只包裝已實作路由，不建立 API、schema 或未決產品 contract。
- [Skills Governance 與 Acceptance](README.md) 定義 profile-installed skill、repo scaffold 的審查、驗收與淘汰流程；使用 [review template](templates/skill-acceptance-review.md) 留下可審查證據。

## Maintenance policy

1. 只引用 vendor／project 官方文件；來源 URL、適用版本或行為改變時重新檢查。
2. Skill 只規範工程流程。凡涉及客流、損耗、品質、聲望、日結、救濟或其他產品規則，必須引用已確認的 architecture decision；沒有 decision 就停止。
3. 每次修改 profile skill 後，若 Hermes 提供 `skill_view`，以它讀回；repo scaffold 則以 `quick_validate.py`（可用時）與直接讀回確認 frontmatter、官方來源、guardrails、verification 與 completion checklist。未經授權不得把 scaffold 自動寫入 profile。
4. 每次 Docs 變更後執行 `git diff --check`；skills 位於 profile 目錄，不會出現在本 repo 的 `git status`，因此本 source map 是 repo 內的可審查索引。
